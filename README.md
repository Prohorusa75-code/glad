# Гладь — сайт-заглушка химчистки для портфолио

Вымышленная химчистка с курьером. Стиль — «жидкое стекло»: тёмная страница,
живой фон из шёлковых складок (WebGL), стеклянные карточки и кнопки-таблетки.

Next.js 16 (App Router) + TypeScript + Tailwind 4, статический экспорт без бэкенда.

## Команды

```bash
npm install
npm run dev      # разработка: http://localhost:3000
npm run build    # статическая сборка в папку out/
```

Публикация — GitHub Actions (`.github/workflows/pages.yml`) собирает сайт с подпапкой `/glad`
и выкладывает на GitHub Pages при каждом пуше в `main`.

## Где что

- `src/app/page.tsx` — страница: первый экран, услуги, цены, этапы, вопросы, заявка.
- `src/lib/data.ts` — тексты, цены, порог бесплатного вывоза.
- `src/components/SilkBackground.tsx` — шейдер «шёлк» (свет следует за курсором).
- `src/components/Order.tsx` — калькулятор и форма заявки с общим состоянием заказа.
- Форма демонстрационная: данные никуда не отправляются.
